# プレミアリーグデータ

プレミアリーグのデータをスマートフォンやPCで確認するための、静的Webアプリのひな型です。

## ローカルで確認する

1. このリポジトリの `index.html` をブラウザーで開きます。
2. 「動作確認」ボタンを押し、「動作確認に成功しました」と表示されることを確認します。

Python 3 がインストールされている場合は、リポジトリのフォルダーで次のコマンドを実行し、`http://localhost:8000` を開く方法もあります。

```bash
python -m http.server 8000
```

終了するときは、サーバーを起動したターミナルで `Ctrl+C` を押します。

## GitHub Pagesで公開する

1. この4ファイル（`index.html`、`style.css`、`app.js`、`README.md`）をリポジトリのルートに置きます。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチとフォルダー（通常は `main` と `/ (root)`）を指定して保存します。
4. Pagesに表示されたURLを開いて確認します。

このひな型のファイルを作成しただけでは、GitHubへのpushや公開設定の変更は行われません。GitHub Pagesは静的ファイルを配信します。画面のボタン動作にはブラウザーで動くJavaScriptを使っています。
